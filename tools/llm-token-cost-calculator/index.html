LLM Token & API Cost Calculator

Before you wire a prompt into an app, know what it costs. Paste your text, pick a model, and see the estimated token count and per-request price — for a single call and at scale.

Migrating from our previous site: this calculator is being rebuilt here as part of the MVP launch, with up-to-date model pricing.

How it will work

  1. Paste your prompt (and, optionally, an expected response length).
  2. Select the model you plan to call.
  3. See estimated input/output tokens, cost per request, and cost per 1,000 requests — then compare models side by side.

Why estimates still help

Every provider counts tokens slightly differently, so any calculator gives an estimate, not an invoice. But an estimate is exactly what you need at design time: to choose between models, to notice that a bloated system prompt costs more than the user's question, and to trim structured data with the JSON to TOON Converter before it reaches the API.
