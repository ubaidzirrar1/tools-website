Pages stay exactly as they are

Merging and splitting here do not rebuild your documents. Each page is copied into the new file exactly as it is — the same text, the same images at the same quality, even the same links and form fields. Text stays selectable and searchable, and a scanned page looks identical to the original. That is the honest difference from Compress PDF: compression has to rebuild pages as images to hit an exact KB limit, while merging and splitting never need to touch the pages themselves. A good workflow is: merge first, then compress the merged file only if a portal's KB limit demands it.

Good to know before you start

  • Order matters when merging. The merged PDF follows the list top to bottom — use the ↑ and ↓ buttons to arrange files before you merge. You can add files in several batches; they are appended to the list.
  • Extracted pages come out in document order. Whatever you type — even 5, 1-3, 2 — the result is pages 1, 2, 3, 5, each once, in ascending order.
  • Splitting gives one file per page. Files are named page-1.pdf, page-2.pdf, and so on, ready to download individually.
  • Limits: merge up to 20 files of 50 MB each; split one PDF of up to 50 MB. Password-protected PDFs cannot be read — remove the password first.

How to use

  1. Choose Merge or Split. The Merge PDF tab combines files; the Split PDF tab pulls pages out of one file.
  2. Add your PDFs. For merging, add two or more files and set their order. For splitting, add one PDF, then type the pages to extract (like 1-3, 5) or choose to split into single pages.
  3. Download the result. One merged PDF, one extracted PDF, or a list of single-page PDFs — ready to upload or share.

Common jobs this tool finishes

  • One upload, many documents: CNIC, degrees and certificates scanned as separate PDFs that a job or admission portal wants as a single file.
  • Only the pages a form asks for: extract the signed pages of an agreement, or the first pages of a bank statement, without sending the whole document.
  • Sharing one page: split a report or book scan and send just page-7.pdf instead of a 200-page file.
  • Fixing a too-big upload: split a long PDF in two, then compress each part with Compress PDF to KB if the portal still rejects it.

Frequently asked questions

How do I merge PDF files online for free?

Open the Merge PDF tab, add two or more PDFs (up to 20 files, 50 MB each), arrange them with the up and down arrows so the order is right, and press Merge PDFs. You get one file called merged.pdf containing every page in your chosen order. There is no sign-up and no watermark.

How do I split a PDF or extract specific pages?

Open the Split PDF tab and add your PDF. To keep only some pages, choose “Extract pages” and type the pages you want — for example 1-3, 5 — then press Extract pages to download one PDF with just those pages. To turn every page into its own file, choose “Split into single pages” and download page-1.pdf, page-2.pdf and so on, one by one.

Will the text in my merged or split PDF still be selectable?

Yes. Merging and splitting here copy each page into the new file exactly as it is — nothing is re-rendered — so text stays selectable and searchable, images keep their original quality, and links and form fields on the pages survive. That is different from Compress PDF, which rebuilds pages as images to reach an exact KB size.

What are the file limits?

For merging: up to 20 PDF files at a time, each up to 50 MB. For splitting: one PDF up to 50 MB. Password-protected PDFs cannot be read — remove the password first, then merge or split the file here.

Is my PDF uploaded to your server?

No. Merging and splitting happen inside your browser on your own device using pdf-lib (an open-source library that downloads once from a public CDN — that is a program file, not your document). Your PDFs are never sent anywhere, never stored and never seen by anyone — which is exactly how CNICs and certificates should be handled.

In what order do extracted pages come out?

Always in ascending page order, with duplicates removed. If you type 5, 1-3, 2 you get pages 1, 2, 3 and 5 — each once, in document order. If a page number does not exist in your PDF, the tool tells you how many pages the PDF actually has instead of failing silently.
